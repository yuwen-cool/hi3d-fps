## 0. 结论

### 0.1 我们现在在哪

**做到的：** 渲染底座（HDR、体积光、SSAO、SSR 水面）、三幕沙暴、火和连锁爆炸、Colossus 巨物、39 组生成音效加三段配乐、40 秒带声预告片；不加辅助的机器人玩家 229 秒通关；平均 60 帧。

**真人试玩的结论：** 不知道怎么玩、场景只有一点点、找不到 BOSS、没有炫酷的东西、不像一个完整的游戏，和别的 FPS 比看不出优势。

**原因：** 缺“像游戏”的一整层（界面、引导、演出、动作、任务、规模），而且前两阶段的验收用了辅助脚本和静帧盲评，没人真玩过。

### 0.2 同类在哪（2026-08 以来推特上的样本）

| 作品 | 卖点 | 数据 |
|---|---|---|
| “手绘”游戏（每帧 150 万笔触） | **一种没见过的画面** | 8,018 赞 / 45.7 万看 |
| SOL | 载具、巨型 BOSS、近战 | 168 万看 |
| 赛车四模式（联机） | 完整度、物理 | 735 赞 |
| 热带岛 FPS（单提示词） | “AAA 写实” | 663 赞 |
| 浏览器 COD | “什么都有”：地图、武器、菜单、手柄 | 503 赞 |
| Saltline | 界面完整、冲刺滑铲、无人机 | 我们的直接对照 |

两个事实：

1. **“写实 + 齐全”已经是大路货。** 做 FPS 的都在说 AAA、都有菜单和武器，数据是几百赞。追平他们等于变成其中之一。
2. **数据最高的赢在“一眼没见过”。** 一种画面、一个玩法点子，两秒内看得出不一样。

所以第三阶段不以追平为目标。界面、引导这些是必须补的底线，但赢要靠别人没有的东西。

## 1. 立意

**一句话：在吞没一切的沙暴里，靠一道扫描波和闪电亮起的瞬间，把整座炼油厂当武器，拆掉一台十层楼高的机器。**

拉开差距的三件事（别人都没有，我们都有底子）：

| | 招牌 | 同类现状 | 我们的底子 |
|---|---|---|---|
| S1 | **沙暴是规则**，不是背景 | 天气静止或只是滤镜 | 会推进的沙墙、体积尘、闪电、风场都已在跑 |
| S2 | **炼油厂是武器**，打什么都有后果 | 场景是布景，最多几个油桶 | 泄漏、点燃、火焰、连锁爆炸、储罐、倒塔都已在跑 |
| S3 | **巨物是关卡**，一块块拆掉它 | 巨型 BOSS 是一条血条 | 四足 IK 步态、光束、核心、按骨骼碎裂都已在跑 |

**不比的：** 地图数量、武器数量、联机、载具。这些拼的是堆量，不出记忆点。

样张（画在我们真实截图上的目标画面）：`out/concept/sheet_M1.jpg`、`sheet_M2.jpg`。

## 2. 招牌层

### S1 沙暴是规则

玩家的感受：沙暴进来之后，这变成了另一个游戏。

- **看不见。** 能见度降到十几米，画面收成焦赭色的剪影，只有光源（火、曳光、机器人目镜、闪电）有颜色。这是一种定下来的画风，不是“雾很大”。
- **扫描脉冲（Q）。** 一圈光波贴着地面和结构扩散出去，扫过的表面短暂露出线框，藏在沙里的敌人被描边几秒。**代价：敌人也收到你的位置**，会朝你合围。看见和暴露是同一个按键。
- **声和光会暴露你。** 沙暴里机器人靠枪口焰和枪声找人：开火后它们朝你最后的位置压过来，停火移动就能甩掉。安静绕后、近战处决成立。
- **爆炸清出一个球。** 榴弹和油桶的冲击波把沙尘推开，留下一个十米的清晰球体，几秒后被风填回。爆炸同时是伤害和视野。
- **闪电。** 打最高的金属：火炬塔、塔吊、Colossus。落点附近的机器人瘫痪两秒，玩家的界面被干扰撕裂。闪电亮起的一瞬全场剪影可见。
- **风。** 火焰和烟顺风倒，火顺风蔓延；榴弹弧线被吹偏；顶风走得慢，顺风冲刺更远。

### S2 炼油厂是武器

玩家的感受：最爽的击杀不是打出来的，是设计出来的。

- **打什么都有反应。** 管道泄漏喷气、罐体凹陷渗油、灯被打灭那一片变黑、阀门被打转、电缆落地带电、沙地扬尘。
- **压力网。** 管线里有气。阀门（E）决定气往哪走；扫描时管线按压力发亮。把气导到一段管子、打漏、点着，就是一道火墙。
- **连锁。** 火沿管廊烧向储罐，储罐鼓胀、开裂、爆炸；栈桥和塔被炸断会砸下来。全程顺风走。
- **环境击杀计分翻倍并播报。** 火烧、砸死、电击、殉爆各有名目。
- **主线就是这套系统：** 第一幕开三个阀门给火炬管线加压，是在给第三幕布置陷阱。

### S3 巨物是关卡

玩家的感受：它从第一分钟就在那儿，最后是我爬上去亲手拆的。

- **第一幕就看得见。** 地平线的沙墙里，每次闪电都照出它的剪影，一幕比一幕近。找不到 BOSS 这件事不存在：玩家盯着它走过来三分钟。
- **它踩过地图。** 进场时踩扁储罐、撞断管廊，走过的地方就是新的地形和新的火。
- **光束烧沙成玻璃。** 扫过的沙地留下发光的熔痕，慢慢冷却，夜里是场上的光源。
- **一块块拆。** 打膝部作动器 → 断腿、跪倒；装甲板被炸飞 → 冷却核心外露；每掉一块，它的行为变一次（三条腿拖行、光束乱扫）。
- **钩索上身。** 它跪下时出现锚点，钩索（右键）把玩家拉上机体，在背上对着核心打完最后一段。
- **陷阱收尾。** 把它引到加压管线出口点火，高塔砸下。

## 3. 质感层

这一层决定“像真的”。

- **会坏的机器人。** 打断手臂换手开火，打断腿在地上爬，打掉头盲射；装甲一片片掉；不同部位不同声音。现有的按骨骼碎裂系统从“死后”提前到“活着的时候”。
- **身体感。** 落地、冲刺、受击、近处爆炸的镜头反应；顶风时镜头压低；枪上积沙；脚印和弹坑被风填平。
- **头盔就是界面。** 界面是一块真玻璃上的显示：受击出现裂纹并折射 HUD，沙粒划过，闪电让它撕裂，护盾破时半屏失灵一瞬。信息和别家一样全，但它是活的。
- **声音跟着沙暴变。** 进沙暴后远处声音变闷、近处更响；扫描、钩索、断肢、玻璃裂各有声音。

## 4. 底线层

别人有、我们必须有的。做法上用 §3 的头盔界面，不照抄别家的样子。

- **屏幕：** 开机自检 → 标题/主菜单（背景是实时场景）→ 部署入场 → 战斗 → 暂停/设置/按键 → 阵亡 → 结算。
- **HUD：** 罗盘和目标点、目标追踪、雷达、分段护盾和血量、弹药、技能冷却、敌人标签、命中和击杀确认、受击方向、击杀播报、无线电字幕、BOSS 分部位血条、警报。每个元素有入场、变化、退场和声音。
- **引导：** 任何时候都有“现在去哪”，罗盘和世界里各标一次；目标变化时界面和无线电同时说。
- **动作：** 冲刺、滑铲、近战、扫描、钩索、交互、开镜；护盾可回复，血量靠补给。
- **演出：** 部署入场、沙暴抵达、空投舱砸地、BOSS 进场（镜头接管不超过 4 秒，可跳过）、陷阱引爆、撤离。
- **无线电语音：** 指挥台短句配音加字幕。

界面风格三选一的样张：`out/concept/sheet_A.jpg`、`sheet_B.jpg`、`sheet_C.jpg`。

## 5. 关卡和任务链

从一个院子扩成三区一条线，每区一个地标，Colossus 的路线贯穿三区。

| 区 | 地标 | 干什么 |
|---|---|---|
| 东院（现有） | 管廊、火炬塔 | 第一幕：落地，阀门 A，学会扫描和环境击杀 |
| 罐区（新） | 一排大储罐、栈桥 | 第一幕：阀门 B、C；第二幕：沙暴抵达，守控制台 |
| 西场（新） | 开阔沙地、管线出口、高塔 | 第三幕：拆巨物、陷阱、撤离 |

任务链：**加压**（三个阀门）→ **守台**（沙暴里守住上传，空投舱一波波落）→ **拆解**（断腿、剥甲、上身、引进陷阱）→ **撤离**（限时）→ 结算。

敌人加两种：带护盾的重装（破盾或绕后或用环境）、无人机（逼玩家抬头，怕闪电）。

## 6. 传播层

- **自动战报。** 一局里最好的三个瞬间（最大连锁、断腿、终结）由游戏自己换一个电影机位各拍一张，结算时拼成一张带成绩的海报，一键保存；终结镜头同时录成一段几秒的短片。玩家发出来的每张图都是我们的广告。
- **Hi3D 透视。** 扫描波扫过时露出的线框就是 Hi3D 生成的真实网格；菜单里有一个机库，每个模型从原图到线框到成品转一圈。“全是 AI 生成的”变成游戏里看得见的东西。
- **预告片重拍：** 地平线上的剪影 → 沙暴吞没 → 扫描 → 清出一个球 → 连锁 → 断腿 → 上身终结。

## 7. 怎么算过关

以玩为准。

| 编号 | 检验 | 做法和线 |
|---|---|---|
| G1 | 你亲自玩 | 每个里程碑给你一个能玩的版本，你说行才往下 |
| G2 | 生手看得懂 | 5 个没见过项目的评审各看 60 秒第一人称录屏，答“要干什么、往哪走、BOSS 在哪、打哪里”，至少 4 人对 |
| G3 | 不加辅助能通关 | `tools/botrun.cjs` 只按屏幕标记走、自己瞄准，全流程通关零报错 |
| G4 | 复述 | 5 个评审看 30 秒后用一句话说这是什么游戏；至少 4 人说到沙暴、环境击杀、拆巨物之一，而不是“沙漠射击”；每人说得出至少两样在别的浏览器射击游戏里没见过的东西 |
| G5 | 盲比 | 同机位对 Saltline、浏览器 COD、热带岛三家，A/B 随机；“更想玩哪个”至少 4/5 |
| G6 | 性能 | 1080p 平均 60 帧，最低不低于 45 |

`tools/flowtest.mjs`（辅助脚本）只用来快速看流程，不算验收。

## 8. 先后顺序和过关条件

### R0 定方向

- **过关：** 你看过画面样张（M1、M2）确认三个招牌的方向，并选一套界面风格（A/B/C）。

### R1 头盔、引导、动作（现有院子）

界面系统和全部 HUD、头盔玻璃效果、开机/标题/部署入场；引导；冲刺、滑铲、近战、护盾、命中和击杀反馈、交互；**扫描脉冲**（含线框和描边）。第一幕先只做阀门 A。

- **过关：** G1 你玩前 90 秒认可；G2“干什么、往哪走”；G5 中标题屏和战斗 HUD 两项；G3；G6。

### R2 沙暴规则和会坏的机器人

沙暴画风定型、扫描的暴露代价、敌人按声光找人、爆炸清球、闪电瘫痪和界面干扰、风对火焰和榴弹的影响；活体断肢和行为变化；沙暴里的声音。

- **过关：** G1；G4 评审里至少 4 人主动提到沙暴里的玩法；机器人玩家用“停火绕后”和“扫描后强攻”两种打法都能过第二幕；G6。

### R3 炼油厂武器化

全场可破坏反应、压力网和阀门、顺风连锁、栈桥和塔的倒塌、环境击杀计分和播报。

- **过关：** G1；录屏里一次环境连锁至少带走 3 个敌人且评审标为“想截图”；机器人玩家只用环境击杀能清掉一波；G6。

### R4 巨物

第一幕起地平线剪影、进场踩毁、熔痕、断腿和剥甲的分阶段、钩索上身、陷阱收尾、分部位血条、进场演出。

- **过关：** G1；G2“BOSS 在哪、打哪里”5/5；G3 机器人靠标记打完全程；G4 评审复述里出现“拆/爬上去”；G6。

### R5 扩图和任务链

罐区、西场、三个阀门、守台、空投舱、两种新敌人、撤离限时、补给重排。

- **过关：** G3 全链通关；G2 评审能按录屏说出三个区的先后；G6 重测；G1。

### R6 收口

无线电配音全量、暂停/设置/按键/阵亡/结算、自动战报海报和终结短片、Hi3D 机库、再来一局。

- **过关：** 标题 → 结算 → 再来一局三遍无死路零报错；战报海报在三局里都拍到了对的瞬间；G1 你完整玩一局。

### R7 成片和上线

预告片重拍和混音、可玩链接、教程帖素材。

- **过关：** G5 全项；G4 用预告片再测一次；链接在另一台机器上能玩；你点头发布。

**顺序的道理：** R1 先补底线并带上扫描这一个招牌，最快让你玩到差别；R2、R3 都在现有院子里做，不依赖新资产，先把“玩法不一样”立住；R4 用到前面全部系统；扩图放在玩法之后，否则只是把空旷放大。每个 R 结束都是一个能玩、能停的版本。

## 11. 需要你定的

1. **三个招牌的方向对不对**（沙暴是规则 / 炼油厂是武器 / 巨物是关卡），有没有要换或要加的。
2. **界面风格选哪套。** 建议 C（工业警示）：黄昏、沙暴、夜三幕里都看得清，和 Colossus 身上的警示条纹是一套语言；B（冷青全息）是 AI 游戏最常见的样子；A（琥珀）在黄昏和沙暴里会和画面糊在一起。
3. **可玩链接放哪**（R7 之前定即可）。

## 附录 A　前两阶段留下的事实（仍然有效）

以下都是实测或核对出来的，不是推测。

### A.1 Hi3D 模型的真实情况（影响最大）

实测两个大师档模型（`out/review/` 里有渲染图）：

| 项 | 实测 | 规格原来的假设 |
|---|---|---|
| 面数 | 500 万三角面 | 200 万 |
| 网格 | 一整块，步枪基本只有 1 个连通块 | 可拆件 |
| 法线 | 没有顶点法线，没有法线贴图 | 有法线贴图 |
| UV | 碎成上千个小片 | 可直接沿用 |
| 底色贴图 | 烘进了明暗和高光 | 基本干净 |
| 贴图 | 8K，但 JPEG 只有约 3 MB，实际细节不到 8K | 8K 细节 |
| 骨骼 | 没有 | 自动绑骨后可用 |

好消息：几何本身质量不错。步枪的铆钉、快慢机、弹匣筋条、瞄具都是真实几何；机器人在交战距离上很能打。

后果和改法：

1. **规格 §3.2 的"直接减面 + 沿用原 UV"作废。** 那样做细节会全丢，碎 UV 还会在接缝处渗色。改成 Blender 流程：焊接 → 减面 → 重新展 UV → 从 500 万面高模烘焙法线、底色、粗糙度、金属度 → 去光照 → 压缩。这和调研里 icebakbum 的结论一致：重拓扑加重烘焙明显好于直接减面。
2. **去光照是必做项**，不是可选项。
3. **面罩的橙色发光条**从底色里提取成自发光遮罩，变成真正的 HDR 发光，同时用作弱点和开火预警。

### A.2 步枪要重做

现在这把（v1）有四个问题：

- 一整块，弹匣卸不下来，换弹没法做。
- 用单张侧视图生成，而 FPS 里玩家看到的是枪的后上方，那一面是模型猜的，没验过。
- 出来的是一把镜像的 AK，带真实品牌外观的瞄具和枪托，懂枪的人一眼能挑出毛病。
- 手护木上有 AI 生成特有的"融化"孔洞。

改法：

- 重新设计成**原创近未来步枪**，用 Hi3D 的多视图出图（前后左右四张）再生成 3D。
- **弹匣单独生成一件**；枪身上的原弹匣用平面切掉并封口。
- 枪机不做活动件，靠后坐、抛壳和枪口火焰带过。
- 验收机位改成 FPS 机位，不再看侧视图。
- v1 保留给敌人手里拿（远看足够）。

### A.3 敌人绑骨和死亡

- 规格里写的"Tripo 绑骨"不能用：这是 Hi3D 的推广，不能出现竞品。
- **首选 Hi3D Agent 的 `rig-retarget` skill。** 这正好是品牌要展示的"不用自己绑骨"。
- 退路：本机已有的 `rig_character.py`（万物对决用过）。
- 机器人是硬表面，按骨骼分区做**刚性蒙皮**（每块装甲只跟一根骨骼），关节处留窄过渡带，装甲不会像橡皮一样变形。
- 动画用本机已有的 mesh2motion CC0 库：跑、冲刺、横移、后退、蹲、举枪、开火、换弹、受击、四种死亡、闪避、翻滚都有。它只有手枪持握，步枪的左手用 IK 贴到护木上。
- **死亡升级成"解体"**：刚性分区本来就是一块块的，击杀时让几块装甲脱落成碎件飞出去，加火花和电弧。比播一段死亡动画有冲击力，也不需要物理引擎。

### A.4 代码来源

- Saltline 的源码是网友转贴的副本，没有许可证；歸藏的 skill 是 AGPL。
- 所以规格里"一字不改照抄"的说法作废：**技术和参数拿来当起点，代码自己写**。我们的场景是黄昏沙漠，参数本来也要重调。发布时注明参考了谁。
