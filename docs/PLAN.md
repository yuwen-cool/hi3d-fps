# hi3d-fps 执行规划（2026-11-20 复审版）

技术参数看 `SPEC.md`，做什么、先后顺序、怎样算过关看本文。两者冲突时以本文为准。

---

## 0. 目标与胜负标准

一款浏览器里能玩的 FPS：画面和手感不输 Saltline，近景资产明显比它真。

"超越"必须能被检验，所以定成 6 条：

| # | 标准 | 怎么验 |
|---|---|---|
| G1 | 武器近景赢 Saltline | 同机位截图，5 个互不相干的评审盲选"哪个更像 3A"，我方 ≥ 4 票 |
| G2 | 敌人近景赢 Saltline | 同上 |
| G3 | 整体画面不输 | `target/t1`、`t2` 机位盲评 ≥ 8/10；和 Saltline 全景盲比 ≥ 3 票 |
| G4 | 流畅 | high 档、M 系 Mac、1080p：平均 ≥ 60 fps，交战最低 ≥ 45 |
| G5 | 手感 | 你亲手玩，开枪、移动、换弹都说"爽" |
| G6 | 完整 | 从标题到撤离的一局 3–5 分钟，没有报错 |

Saltline 的对照截图在 M0 就拍好存档（它自带 `?shot`、`?cam`），之后每个闸门都拿来比。

## 1. 复审结论：规格里要改的地方

以下都是实测或核对出来的，不是推测。

### 1.1 Hi3D 模型的真实情况（影响最大）

实测两个大师档模型（`out/review/` 里有渲染图）：

| 项 | 实测 | 规格原来的假设 |
|---|---|---|
| 面数 | 500 万三角面 | 200 万 |
| 网格 | 一整块，步枪基本只有 1 个连通块 | 可拆件 |
| 法线 | 没有顶点法线，没有法线贴图 | 有法线贴图 |
| UV | 碎成上千个小片 | 可直接沿用 |
| 底色贴图 | 烘进了明暗和高光 | 基本干净 |
| 贴图 | 8K，但 JPEG 只有约 3 MB，实际细节不到 8K | 8K 细节 |
| 骨骼 | 没有 | 自动绑骨后可用 |

好消息：几何本身质量不错。步枪的铆钉、快慢机、弹匣筋条、瞄具都是真实几何；机器人在交战距离上很能打。

后果和改法：

1. **规格 §3.2 的"直接减面 + 沿用原 UV"作废。** 那样做细节会全丢，碎 UV 还会在接缝处渗色。改成 Blender 流程：焊接 → 减面 → 重新展 UV → 从 500 万面高模烘焙法线、底色、粗糙度、金属度 → 去光照 → 压缩。这和调研里 icebakbum 的结论一致：重拓扑加重烘焙明显好于直接减面。
2. **去光照是必做项**，不是可选项。
3. **面罩的橙色发光条**从底色里提取成自发光遮罩，变成真正的 HDR 发光，同时用作弱点和开火预警。

### 1.2 步枪要重做

现在这把（v1）有四个问题：

- 一整块，弹匣卸不下来，换弹没法做。
- 用单张侧视图生成，而 FPS 里玩家看到的是枪的后上方，那一面是模型猜的，没验过。
- 出来的是一把镜像的 AK，带真实品牌外观的瞄具和枪托，懂枪的人一眼能挑出毛病。
- 手护木上有 AI 生成特有的"融化"孔洞。

改法：

- 重新设计成**原创近未来步枪**，用 Hi3D 的多视图出图（前后左右四张）再生成 3D。
- **弹匣单独生成一件**；枪身上的原弹匣用平面切掉并封口。
- 枪机不做活动件，靠后坐、抛壳和枪口火焰带过。
- 验收机位改成 FPS 机位，不再看侧视图。
- v1 保留给敌人手里拿（远看足够）。

### 1.3 敌人绑骨和死亡

- 规格里写的"Tripo 绑骨"不能用：这是 Hi3D 的推广，不能出现竞品。
- **首选 Hi3D Agent 的 `rig-retarget` skill。** 这正好是品牌要展示的"不用自己绑骨"。
- 退路：本机已有的 `rig_character.py`（万物对决用过）。
- 机器人是硬表面，按骨骼分区做**刚性蒙皮**（每块装甲只跟一根骨骼），关节处留窄过渡带，装甲不会像橡皮一样变形。
- 动画用本机已有的 mesh2motion CC0 库：跑、冲刺、横移、后退、蹲、举枪、开火、换弹、受击、四种死亡、闪避、翻滚都有。它只有手枪持握，步枪的左手用 IK 贴到护木上。
- **死亡升级成"解体"**：刚性分区本来就是一块块的，击杀时让几块装甲脱落成碎件飞出去，加火花和电弧。比播一段死亡动画有冲击力，也不需要物理引擎。

### 1.4 代码来源

- Saltline 的源码是网友转贴的副本，没有许可证；歸藏的 skill 是 AGPL。
- 所以规格里"一字不改照抄"的说法作废：**技术和参数拿来当起点，代码自己写**。我们的场景是黄昏沙漠，参数本来也要重调。发布时注明参考了谁。

### 1.5 规格里缺的

| 缺口 | 补法 |
|---|---|
| 环境资产没有清单。目标图里炼油厂的密度是全片最大的工作量 | 见 §3 的模块化套件，加程序化管线和钢架，加远景剪影 |
| 手臂方案（Hi3D 手臂 + 绑骨 + 手指 IK）风险最高、收益最低 | 改成两只固定握姿的手套手，刚体挂在枪上；换弹时左手带着弹匣走。退路是只露袖口 |
| 音频没有落实来源 | 枪声用合成分层打底，能找到的 CC0 采样再叠上去；配乐要你用 Suno 出，我写提示词 |
| 没有成片采集方案 | 加"输入录制回放 + 固定步长离线逐帧 4K 渲染"，录出来的画面稳定在 60 帧，不靠录屏 |
| 顺序上把最不确定的东西放得太靠后 | 见 §4 的 M3"主视觉闸门"：先证明画面能赢，再铺玩法 |
| KTX 压缩工具本机没有，Homebrew 里也没有 | 用 npm 的 wasm 编码器，不装系统级软件 |

### 1.6 维持原规格的决定

后处理全部自己写（不用 pmndrs 库）；户外用积尘、长廊地面保留积水；不引入物理引擎；Vite 多模块工程；three 钉死 0.187.0。

## 2. 作品范围

**做：**

- 关卡：黄昏沙漠里的废弃炼油厂。庭院约 40×30 m，加一条约 25×6 m 的室内长廊。
- 一局：开场巡逻 → 三波敌人 → 撤离点，3–5 分钟。
- 玩家：一把步枪。腰射、开镜、换弹、冲刺、蹲、跳。
- 敌人：人形战斗机器人，面罩是弱点。会找掩体、轮流开火、受击有反应、死亡解体。
- 环境反应：分表面的命中效果和弹孔、油桶爆炸、子弹打起沙尘。

**不做：** 多武器、手雷、载具、存档、手机端、多人。

**加项（核心全部过关后才考虑）：** 无人机敌人。

## 4. 里程碑：先后顺序和过关条件

M1 和 M2 可以同时做。M3 过关之后，M4、M5、M6 可以同时做。

### M0 工具和基线

- 工程骨架、依赖清理、截图脚本（必须是真 GPU，不是软件渲染）。
- 拍 Saltline 对照图：武器近景、敌人、全景各一张。

过关：截图脚本出图且显卡是 Apple GPU；对照图存进 `out/baseline/`。

### M1 资产烘焙管线

- Blender 脚本：焊接 → 减面 → 重展 UV → 烘焙四张贴图 → 去光照 → 导出。
- 先用步枪 v1 跑通。

过关：同机位下，低模和 500 万面高模并排，评审分不清哪个是高模；步枪 ≤ 15 万面、文件 ≤ 12 MB。

进展：第一版已跑通。步枪从 499 万面减到 15 万面，烘焙全程 63 秒，并排看几乎分不出（`out/review/bake_compare.jpg`），文件 9 MB。还剩三件事：锐边上有少量烘焙漏光斑点、去光照、KTX2 压缩。

### M2 渲染底座

- 程序天空、低角度太阳、软阴影、体积光、AO、泛光、自动曝光、色调映射、调色、抗锯齿、颗粒；画质档位和动态分辨率。
- 场景只放灰盒。

过关：灰盒庭院里逆光的体积光束成立；粗糙度球阵列看着对；跑分达到 G4。

### M3 主视觉闸门 ★

- 步枪 v2 生成、烘焙，进第一人称视图。
- 机器人静态站进灰盒庭院，用最终布光。

过关：G1、G2 赢 Saltline。**不过关就停下来重想资产或布光，不往后铺。**

### M4 关卡

- 环境套件逐件生成 → 烘焙 → 布置；长廊；碰撞、掩体点、导航网格；积尘材质；远景。

过关：t1、t2 机位盲评 ≥ 8；全图扫描没有会卡住玩家的点。

### M5 武器和手感

- 姿态、弹簧、射击、散布、后坐、开镜、换弹、火焰、弹壳、曳光、命中效果、贴花；移动、跳跃、镜头。
- 两只手套手。

过关：贴墙转一圈武器不穿墙；你试玩通过。

### M6 敌人

- 绑骨 → 刚性蒙皮校正 → 动画 → AI → 解体死亡 → 波次。

过关：抬手、弯腿、下蹲这些极端姿势不穿模；能完整打完三波；满波交战 ≥ 45 fps。

### M7 音频

- 引擎、枪声分层、室内外混响、脚步、命中、敌人、环境、配乐。

过关：离线混音检查不削波；你戴耳机试听通过。

### M8 流程和打包

- 标题、开场、目标提示、撤离、死亡重来；HUD；生产构建；部署。

过关：G6；本地首屏到可玩 ≤ 10 秒。

### M9 打磨循环

- 对着目标图逐轮改，每轮新开评审盲评；和 Saltline 盲比；性能；你至少两轮试玩反馈。

过关：G1–G6 全部满足。

### M10 采集

- 输入回放加离线 4K 逐帧渲染。
- 教程素材从 M1 起自动存档：每一步的前后对比图。

过关：一段 60 帧 4K 的实机画面，没有掉帧和录屏痕迹。

## 5. 风险和退路

| 风险 | 退路 |
|---|---|
| 烘焙后近看细节不够 | 步枪是唯一的近景资产，面数提到 25 万、法线保持 4K，预算放得下 |
| 多视图步枪仍有糊边、融化 | 换角度重出概念图，最多 3 次；再不行用 v1 加切割 |
| Hi3D Agent 绑骨效果差 | 换本机的 `rig_character.py` |
| 手枪动画配步枪别扭 | 上身改成程序化瞄准，只保留腿部动画 |
| 环境密度追不上目标图 | 多用实例化和程序化管线；用雾和机位收窄视野 |
| 帧率不够 | 动态分辨率 → 降档 |
| 我听不到声音、感觉不到手感 | 这两项只能靠你试 |
