第一阶段（M0–M8：管线、渲染底座、关卡、武器、敌人、音频、流程）已完成并提交，结论见 §0，沉淀的事实在附录 A。

## 0. 第一阶段的结论

五轮盲评（每轮 5 个互不相干的评审，A/B 随机）加逐帧复看录像：

| 项 | 结果 |
|---|---|
| 敌人近景 vs Saltline | 25/25 赢（对方构图差，有水分） |
| 武器近景 vs Saltline | 1、2、3、4、2 票，不稳 |
| 全景 vs Saltline | 0/25 |
| 对照 AI 概念图 | t1 4→4.6，t2 3.8→5.1（线是 8） |
| 性能 / 完整性 | 60 帧、p99 18.8 ms、整局零报错 |
| 交火录像 | 10 秒抽 12 帧，只有 1 帧看得出在打仗 |

三个判断：

1. **静态画质的回报已经见底。** 五轮打磨 t1 只涨 0.6 分，再抠贴图和雾换不来票。
2. **真正缺的是"事件"。** 画面里没有东西在发生：敌人是远处的小点，爆炸两帧就没，光照从头到尾一个样。
3. **和同类没有区别。** 现在是"又一个沙漠 FPS"。同类 AI 游戏的共同点是静态光照、空旷场地、打站桩——我们也是。

所以第二阶段不再追静帧，改追三件会动的东西。

## 1. 定位：沙暴压境的炼油厂

**一关，三到四分钟，三幕。** 名字 SANDLINE 就是地平线上那道压过来的沙墙。

| 幕 | 光 | 发生什么 |
|---|---|---|
| 一　黄昏 | 现在的金色逆光；远处地平线上有一道沙墙在逼近 | 巡逻遭遇、第一波近距离交火 |
| 二　沙暴 | 沙墙吞没厂区：天色压成暗橙褐，能见度二十米，闪电 | 第二波在沙里打，靠面罩光、曳光、枪口焰和火找人 |
| 三　火夜 | 天黑，被打爆的厂区自己在烧，火光是唯一光源 | 巨型机甲从沙里走出来；打完撤离 |

三根支柱，每根都是"同类没有、我们引擎底子正好接得上"的：

- **天气即剧情。** 一道真的会到达的沙暴锋面，不是开关式的雾。接现有的带阴影体积光和自动曝光。
- **厂区即武器。** 阀门、管线、储罐、火炬塔都能被打坏、点着、殉爆，并且反过来成为第三幕的照明。接现有的油桶爆炸、粒子、动态点光。
- **巨物。** 一台比储罐还高的采油机甲，腿用程序化步态驱动、不绑骨——这正好是品牌要讲的"不用绑骨"，而且比人形敌人上镜得多。光束武器切过沙尘时，体积光会把光束"画"出来。

三幕各自像一款不同的游戏，预告片不再是 30 秒同一种橙色。

## 2. 范围

**做（新增）：**

- 战斗演出：近距离遭遇、双向曳光、命中反馈、机器人解体、立体枪口焰、可见的抛壳、震屏、顿帧、收尾慢动作。
- 火系统：火焰、热浪扭曲、火光进体积光、爆炸重做（闪光→火球→冲击环→碎片拖尾→滞留浓烟→焦痕）。
- 可破坏厂区：阀门/管线泄漏成喷流并可点燃、储罐殉爆换残骸、火炬塔、终局蒸馏塔倒塌。
- 沙暴：锋面推进、光照过渡、横飞沙粒、闪电、风声。
- Boss：四足采油机甲，程序化步态、光束、弱点、倒地连锁爆炸。
- 一把下挂榴弹（3 发）：让玩家随时能自己制造爆炸。
- 一种冲锋型机器人（同一个模型，换行为和面罩颜色）：保证画面里有近处的敌人。
- 场景活化：抽油机会点头、风扇会转、吊灯会晃、断缆冒电火花、蒸汽口、可上的二层栈桥（看沙暴的高点）。

**顺手清掉的遗留问题**（评审反复点名的）：逆光雾把中景洗白、枪托过曝、枪口焰是平面贴片、敌人交战距离太远。

**不做：** 第二张地图、多人、存档、手机端、更多枪、无人机、再对着 AI 概念图调静态画质。

## 3. 怎么算过关

静帧对比换成对视频有效的验法。评审每次都新开、互不相干、不知道哪个是我们的。

| # | 标准 | 怎么验 | 现在 |
|---|---|---|---|
| V1 | 事件密度 | 交火录像每 0.5 秒抽一帧共 20 帧，评审逐帧写"这一帧在发生什么"；≥16 帧写得出具体事件 | 抽 12 帧只有 1 帧 |
| V2 | 辨识度 | 我们 4 张和其他浏览器 FPS 的 4 张混排，评审选最有记忆点的 3 张并各写一句话；≥4/5 的评审至少选中我们 2 张，且描述里出现沙暴、火或巨型机甲 | 未测 |
| V3 | 三幕成立 | 同机位三幕各一张；5/5 认出是同一地点的不同时刻，每张单独按"像不像已发售游戏的截图"打分 ≥7 | 只有一幕 |
| V4 | 全景不输 | 和 Saltline 全景盲比 ≥3/5（第一阶段没过，继续验） | 0/5 |
| V5 | 流畅 | high 档 1080p 平均 ≥60；沙暴 + 火 + Boss 同屏最低 ≥45 | 60（无新特效） |
| V6 | 手感和声音 | 你亲手玩两轮：N1 过关后一次，N5 过关后一次 | 没玩过 |
| V7 | 完整 | 机器人自动打完三幕一整局，零报错 | 旧流程已过 |

## 4. 里程碑：先后顺序和过关条件

顺序的道理：一切都是透过战斗被看到的，所以战斗先；沙暴必须有局部光源撑着才不会糊成一片，所以火在沙暴前；Boss 的登场要沙暴、死亡要爆炸，所以排在两者之后。

### N1 战斗底盘

- 敌人交战距离从 8–20 米收到 6–14 米；加冲锋型；开局巡逻位贴近玩家出生点。
- 双向曳光、分表面命中火花和碎屑加量、机器人中弹掉甲片。
- 解体死亡：加载时按主导骨骼把蒙皮网格拆成刚性块（模型已带骨骼权重，不需要重新绑骨），击杀时整具散开，断面封暗色加电弧。
- 枪口焰改成立体的（十字片 + 前向锥 + 一帧点光），抛壳加亮、加落地声。
- 震屏、命中顿帧、每波最后一击慢动作。
- 清遗留：压低逆光雾、拉中景对比；枪托降亮。

过关：V1 ≥16/20；贴脸、侧面、背后三个角度击杀，碎块不穿地、不闪烁；V6 第一轮试玩。

### N2 火与爆炸

- 火焰着色器（噪声驱动的体积感火舌，HDR 发光）、热浪屏幕扭曲、余烬。
- 火光作为点光进入体积光步进，让火在烟尘里有光晕。
- 爆炸重做成六层；下挂榴弹接上。
- 阀门和管线：打漏 → 白色喷流 → 遇火成火舌，可以烧到敌人。
- 储罐殉爆：换成 Hi3D 生成的残骸模型，冲击波推倒附近敌人。
- 火炬塔常燃，全图可见。

过关：爆炸录像逐帧看，闪光到浓烟的层次持续 ≥1.5 秒且每层分得清；关掉太阳只靠火光，10 米内敌人看得清；满负载 ≥45 帧。

### N3 沙暴

- 沙墙：开局在地平线，随波次推进，到达时有一道清晰的锋面扫过厂区。
- 光照过渡：太阳被遮、天空压暗、雾色跟着变、自动曝光跟上，全程连续不跳变。
- 横飞沙粒和碎屑、物件上的沙流、闪电（闪一下把整个沙体照亮）、风噪。
- 沙里的可读性靠光源：面罩、曳光、枪口焰、火、闪电。

过关：V3 的"黄昏 / 沙暴"两张过；沙暴里 15 米内的敌人评审指得出来；锋面经过的 3 秒录像没有一帧跳变。

**这是最容易做砸的一项**——评审五轮都在骂"雾把画面洗白"。做法是"暗 + 局部光源"，不是"亮雾"。

### N4 巨物

- 资产：机体、大腿节、小腿节、足、光束炮分件用 Hi3D 生成（同一张母图拆件，保证风格统一）。
- 程序化步态：落脚点规划、机身随步起伏、踩地扬尘和震屏；不做蒙皮。
- 武器：蓄能 → 扫射光束，烧出焦痕、点燃沿途的泄漏点；光束在沙尘里可见。
- 弱点：发光的冷却罐，打掉一个瘸一条腿。
- 死亡：跪倒 → 连锁爆炸 → 压垮一段管廊。

过关：行走无滑步、不穿地；登场镜头在 V2 里被评审选中；打得死、打得完；V5。

### N5 三幕编排和场景活化

- 波次节奏对上三幕；Boss 死后蒸馏塔倒塌、撤离点亮起。
- 场景活化清单全部接上；二层栈桥可上。
- 第三幕只用火光和闪电照明。

过关：V3 三张全过；V7；一局 3–4 分钟；V6 第二轮试玩。

### N6 声音

- 合成音换成 CC0 实录采样，每种 ≥3 个变体随机音高；室内外混响；Boss 的脚步和蓄能有低频。
- 配乐三幕各一段，随幕切换。

过关：离线混音不削波；你戴耳机通过。

### N7 上线和采集

- 生产构建、部署，出试玩链接；首屏到可玩 ≤10 秒。
- 预告片重剪：前 3 秒是沙墙里的巨物剪影，然后才是标题。
- 教程素材：每件 Hi3D 资产的"原始 → 烘焙后 → 进游戏"三联图、积分账单、工具清单、已知局限。

过关：V1–V7 全过；V4 复测。

## 6. 风险和退路

| 风险 | 退路 |
|---|---|
| 沙暴把画面糊成一片 | 降密度、缩短第二幕；底线是保留"锋面扫过"那几秒和之后的暗场 |
| 体积光加点光源后掉帧 | 点光数量按档位裁；medium 档只留最近 2 个 |
| Boss 步态显假 | 改成固定式：半埋的钻机炮台，光束和弱点照旧 |
| 分件生成比例对不上 | 生成整机，在 Blender 里按连通块拆 |
| 解体碎块露出空心 | 断面封口加火花和烟遮住；只在击杀瞬间近看 |
| 范围膨胀 | **N1–N3 是底线，做完就是一个能发的版本**；N4 是唯一可以整项砍掉的 |
| 我听不到声音、感觉不到手感 | 只能靠你试，所以 V6 排了两次 |

## 附录 A　第一阶段留下的事实（仍然有效）

以下都是实测或核对出来的，不是推测。

### A.1 Hi3D 模型的真实情况（影响最大）

实测两个大师档模型（`out/review/` 里有渲染图）：

| 项 | 实测 | 规格原来的假设 |
|---|---|---|
| 面数 | 500 万三角面 | 200 万 |
| 网格 | 一整块，步枪基本只有 1 个连通块 | 可拆件 |
| 法线 | 没有顶点法线，没有法线贴图 | 有法线贴图 |
| UV | 碎成上千个小片 | 可直接沿用 |
| 底色贴图 | 烘进了明暗和高光 | 基本干净 |
| 贴图 | 8K，但 JPEG 只有约 3 MB，实际细节不到 8K | 8K 细节 |
| 骨骼 | 没有 | 自动绑骨后可用 |

好消息：几何本身质量不错。步枪的铆钉、快慢机、弹匣筋条、瞄具都是真实几何；机器人在交战距离上很能打。

后果和改法：

1. **规格 §3.2 的"直接减面 + 沿用原 UV"作废。** 那样做细节会全丢，碎 UV 还会在接缝处渗色。改成 Blender 流程：焊接 → 减面 → 重新展 UV → 从 500 万面高模烘焙法线、底色、粗糙度、金属度 → 去光照 → 压缩。这和调研里 icebakbum 的结论一致：重拓扑加重烘焙明显好于直接减面。
2. **去光照是必做项**，不是可选项。
3. **面罩的橙色发光条**从底色里提取成自发光遮罩，变成真正的 HDR 发光，同时用作弱点和开火预警。

### A.2 步枪要重做

现在这把（v1）有四个问题：

- 一整块，弹匣卸不下来，换弹没法做。
- 用单张侧视图生成，而 FPS 里玩家看到的是枪的后上方，那一面是模型猜的，没验过。
- 出来的是一把镜像的 AK，带真实品牌外观的瞄具和枪托，懂枪的人一眼能挑出毛病。
- 手护木上有 AI 生成特有的"融化"孔洞。

改法：

- 重新设计成**原创近未来步枪**，用 Hi3D 的多视图出图（前后左右四张）再生成 3D。
- **弹匣单独生成一件**；枪身上的原弹匣用平面切掉并封口。
- 枪机不做活动件，靠后坐、抛壳和枪口火焰带过。
- 验收机位改成 FPS 机位，不再看侧视图。
- v1 保留给敌人手里拿（远看足够）。

### A.3 敌人绑骨和死亡

- 规格里写的"Tripo 绑骨"不能用：这是 Hi3D 的推广，不能出现竞品。
- **首选 Hi3D Agent 的 `rig-retarget` skill。** 这正好是品牌要展示的"不用自己绑骨"。
- 退路：本机已有的 `rig_character.py`（万物对决用过）。
- 机器人是硬表面，按骨骼分区做**刚性蒙皮**（每块装甲只跟一根骨骼），关节处留窄过渡带，装甲不会像橡皮一样变形。
- 动画用本机已有的 mesh2motion CC0 库：跑、冲刺、横移、后退、蹲、举枪、开火、换弹、受击、四种死亡、闪避、翻滚都有。它只有手枪持握，步枪的左手用 IK 贴到护木上。
- **死亡升级成"解体"**：刚性分区本来就是一块块的，击杀时让几块装甲脱落成碎件飞出去，加火花和电弧。比播一段死亡动画有冲击力，也不需要物理引擎。

### A.4 代码来源

- Saltline 的源码是网友转贴的副本，没有许可证；歸藏的 skill 是 AGPL。
- 所以规格里"一字不改照抄"的说法作废：**技术和参数拿来当起点，代码自己写**。我们的场景是黄昏沙漠，参数本来也要重调。发布时注明参考了谁。

### A.5 规格里缺的

| 缺口 | 补法 |
|---|---|
| 环境资产没有清单。目标图里炼油厂的密度是全片最大的工作量 | 见 §3 的模块化套件，加程序化管线和钢架，加远景剪影 |
| 手臂方案（Hi3D 手臂 + 绑骨 + 手指 IK）风险最高、收益最低 | 改成两只固定握姿的手套手，刚体挂在枪上；换弹时左手带着弹匣走。退路是只露袖口 |
| 音频没有落实来源 | 枪声用合成分层打底，能找到的 CC0 采样再叠上去；配乐要你用 Suno 出，我写提示词 |
| 没有成片采集方案 | 加"输入录制回放 + 固定步长离线逐帧 4K 渲染"，录出来的画面稳定在 60 帧，不靠录屏 |
| 顺序上把最不确定的东西放得太靠后 | 见 §4 的 M3"主视觉闸门"：先证明画面能赢，再铺玩法 |
| KTX 压缩工具本机没有，Homebrew 里也没有 | 用 npm 的 wasm 编码器，不装系统级软件 |

### A.6 维持原规格的决定

后处理全部自己写（不用 pmndrs 库）；户外用积尘、长廊地面保留积水；不引入物理引擎；Vite 多模块工程；three 钉死 0.187.0。
